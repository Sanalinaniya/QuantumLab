# ⚛️ QuantumLab — Quantum Mechanics Visualizer

An interactive Python-based visualization project for exploring fundamental concepts in quantum mechanics.

## 🚀 Current Modules

### 1. Particle in a Box
Interactive visualization of the infinite square-well potential.

Features:
- Wavefunctions ψₙ(x)
- Probability density |ψₙ(x)|²
- Comparison of quantum states
- Energy levels
- Adjustable box length
- Normalization check

### 2. Quantum Harmonic Oscillator
Interactive visualization of the quantum harmonic oscillator.

Features:
- Adjustable quantum number n
- Adjustable angular frequency ω
- Wavefunction ψₙ(x)
- Probability density |ψₙ(x)|²
- Energy levels
- Classical turning points
- Node visualization
- Parity information
- Normalization check
- Expectation values ⟨x⟩ and ⟨p⟩

### Module 3 — Quantum Wave Packet

An interactive visualization of a free-particle Gaussian wave packet and its
time evolution.

Features:
- Adjustable initial position
- Adjustable momentum
- Adjustable packet width
- Real and imaginary components of the wavefunction
- Probability density |Ψ(x,t)|²
- Play, pause and reset controls
- Expectation values <x> and <p>
- Position and momentum uncertainties Δx and Δp
- Uncertainty principle verification
- Uncertainty evolution over time

## 🛠️ Technologies

- Python
- NumPy
- Matplotlib
- Tkinter

QuantumLab aims to make quantum-mechanical concepts more intuitive by connecting mathematical descriptions with interactive visualizations.
