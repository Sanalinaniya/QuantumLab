# ⚛️ QuantumLab — Quantum Mechanics Visualizer

An interactive Python-based visualization project for exploring fundamental concepts in quantum mechanics.

## 🚀 Current Modules

### 1. Particle in a Box
Interactive visualization of the infinite square-well potential.

Features:
- Wavefunctions ψₙ(x)
- Probability density |ψₙ(x)|²
- Comparison of quantum states
- Energy levels
- Adjustable box length
- Normalization check

### 2. Quantum Harmonic Oscillator
Interactive visualization of the quantum harmonic oscillator.

Features:
- Adjustable quantum number n
- Adjustable angular frequency ω
- Wavefunction ψₙ(x)
- Probability density |ψₙ(x)|²
- Energy levels
- Classical turning points
- Node visualization
- Parity information
- Normalization check
- Expectation values ⟨x⟩ and ⟨p⟩

## 🛠️ Technologies

- Python
- NumPy
- Matplotlib
- Tkinter

## 🎯 Project Goal

QuantumLab aims to make quantum-mechanical concepts more intuitive by connecting mathematical descriptions with interactive visualizations.
